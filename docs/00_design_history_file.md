# 00 Design History File (index)

**Project:** Hemodynamic Decision Support: three deployment concepts for the Version 5 physics-informed model
**Method:** *Biomedical Engineering Design* (Tranquillo, Goldberg & Allen, Elsevier 2023), referred to below as **BMED**
**Status:** Concept selection complete; working software prototype of all three concepts verified on held-out data
**Selected concept:** **Concept A**, the integrated deterioration alert, forecast and intervention-response monitor, with Concept C's review report folded in as its documentation module (see [04 Concept selection](04_concept_selection.md))

BMED Section 6.8 says to keep design decisions and their evidence in a Design History File (DHF), so that a reviewer can trace every requirement to its verification. This folder is that file. Each document matches one stage of the BMED design process:
